# Rathore Rishtey - Digital Matrimony & Business Directory

A React + TypeScript application for Rathore Samaj members, providing digital matrimony biodatas, local business listings, digitized annual e-booklets, and community event announcements.

## Features

- **Matrimony Bios**: Searchable and filterable matrimonial profiles (by keywords, Grooms/Brides, Gotra, and City) with verified photo cards and detailed biodatas.
- **Fair-Share Access System**: Includes 3 free full contact views for new visitors, and unlocked unlimited views once a family contributes their own profile to strengthen the Samaj directory.
- **Business Directory & Ads**: Community shop and service network with category filtering, special Samaj member discount badges, featured shop status, and direct contact options.
- **Interactive Digital E-Book**: Flippable annual directory e-book with cover page, president's message, executive committee roster, groom/bride indexes, and printable PDF export.
- **Samaj Events & News**: Notices for upcoming Parichay Sammelans with dates, venues, committee contact numbers, and official registration links.
- **Community Contributions**: Dedicated multi-field forms to register matrimonial biodatas, post business advertisements, or submit event announcements.
- **Authentication**: Seamless Google and Phone OTP simulation flows with state persistence.
- **WhatsApp Sharing**: Floating one-click share button to invite Rathore Samaj families directly via WhatsApp.

## Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler & Tooling**: Vite
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
